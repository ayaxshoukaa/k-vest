Read replit.md and follow its stack and rules. Build the app one feature at a time, in the MVP order listed there, and stop after each feature so I can test it. Explain each change briefly.

Global design: very simple and clean, mostly white, one deep-blue accent, big readable text, rounded cards, very little text, icons and numbers over sentences. Mobile friendly. English and Arabic toggle (RTL for Arabic). Footer on every page: "For education only. Not financial advice."

FEATURE 1: LOGIN
Centered card with email, password, a big Login button, "Create account" and "Continue as guest". On load, an animated mouse cursor glides to the Login button and "clicks" it (button presses down with a ripple). Play it once, make it skippable, use CSS/JS only. Accounts stored in MongoDB with hashed passwords and JWT or session auth.

FEATURE 2: MARKET SCANNER
Top: Boursa Kuwait Premier Market index with today's % change. Tabs: Top Gainers, Top Losers, Most Active. Each row: company, price in KWD, % change (green/red), tiny sparkline, and a simple rating badge (Strong / Neutral / Weak) based on momentum and volume. Tap a company for a 1-month chart. Star icon adds it to a Watchlist page. Data: Oanor API (https://api.oanor.com/kuwait-stock-api/v1/screener and /v1/quote, header x-oanor-key) plus yahoo-finance2 for history. Cache 5 minutes. Show friendly error and sample data if loading fails. Note: "Prices may be delayed."

FEATURE 3: AI ASSISTANT
Simple chat with bubbles, typing animation and 4 suggested question chips. Also an "Analyze with AI" button on each stock page that returns a short, plain-language summary of strengths, risks and a simple outlook. Backend calls Anthropic (claude-sonnet-4-6) with this system prompt: "You are a friendly assistant for beginner investors in Kuwait. Answer briefly, in the user's language (English or Arabic). Use the provided market data. Never give personal financial advice; remind users investing carries risk." Pass the latest scanner data into the context.

FEATURE 4: INVESTMENT CALCULATOR
Inputs: budget in KWD, chosen company (auto-fill price), buy price, target/sell price, dividends (optional), years held. Output card: profit/loss in KWD, ROI %, annualized return, and a simple low/medium/high risk label. Counting-up number animation.

FEATURE 5: PRACTICE MODE
Each user gets a virtual 1,000 KWD wallet, clearly labeled "Demo - not real money". Buy and sell Kuwaiti stocks at current prices, show portfolio value, profit/loss, ROI %, and trade history. Reset button. Optional top-10 leaderboard (usernames only, opt-out). Save per user in MongoDB.
